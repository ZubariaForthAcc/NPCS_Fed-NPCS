# Dataset Generation and Reification

This document describes how datasets used in the experiments were generated
and how provenance was encoded using different reification schemes.

---

## 1. Dataset Sources

### WatDiv
- Generator: https://dsg.uwaterloo.ca/watdiv/
- Or direct download 10M: https://dsg.uwaterloo.ca/watdiv/watdiv.10M.tar.bz2   100M: https://dsg.uwaterloo.ca/watdiv/watdiv.100M.tar.bz2 
- Output format: N-Triples (`.nt`)

### Wikidata
- Source: Official Wikidata RDF dumps
- e.g https://doi.org/10.6084/m9.figshare.19599589

### FedShop
- Source: FedShop dataset : [https://zenodo.org/records/12204740](https://zenodo.org/records/12204740/files/fedshop_dataset.zip?download=1)
- Data distributed across multiple SPARQL endpoints

## 2. RDF-star Reification
RDF-star datasets are generated by transforming standard N-Triples produced by
WatDiv into RDF-star annotated triples, where each triple is enriched with
provenance metadata.

### Example: WatDiv-10M Dataset
### Step 1: Download and Extract WatDiv-10M

```bash
wget https://dsg.uwaterloo.ca/watdiv/watdiv.10M.tar.bz2
tar -xvjf watdiv.10M.tar.bz2

```
The extracted directory contains WatDiv data in N-Triples (.nt) format.

Example input file:
```bash
watdiv_10M.nt
```
### Step 2: Generate RDF-star Representation

The following pipeline converts WatDiv-10M N-Triples into RDF-star format by
annotating each triple with a unique provenance statement identifier.
```bash
gzip watdiv_10M.nt

zcat watdiv_10M.nt.gz | \
awk '{print " ", $0, "{| <http://example.org/occurrenceOf> <http://example.org/statement/" NR "> |} ."}' | \
sed -e 's/\t/ /g' -e 's/\. {|/{|/' | \
gzip > watdiv_10M-rdf-star.ttls.gz

```

### Step 3: Finalize RDF-star File
```bash
gunzip watdiv_10M-rdf-star.ttls.gz
sed -i 's/\.{|/{|/g' watdiv_10M-rdf-star.ttls

```
The resulting file:
```bash
watdiv_10M-rdf-star.ttls

```
contains the RDF-star encoded version of the WatDiv-10M dataset and is used as
input for RDF-star experiments in NPCS.

### Step 4: Load into Triple Store (Example: GraphDB)

```bash
graphdb-import --repository watdivrdfstargraphdb \
               --file watdiv_10M-rdf-star.ttls


```

Notes

- The same transformation pipeline is applied to WatDiv-100M and other WatDiv
variants by replacing the input file name.

- The provenance predicate
<http://example.org/occurrenceOf>
is used consistently across all RDF-star experiments to link statements to
provenance identifiers.

- All RDF-star datasets used in the experiments are generated deterministically
using this procedure.

## 3. Other Reification Schemes

We generate the following additional provenance encodings:

- Standard RDF reification

- Named Graphs

- Wikidata-style qualifiers

- Wikidata-real (official Wikidata schema)

1. Each scheme follows the same workflow:

2. Start from the same base .nt dataset

3. Apply a deterministic transformation script

4. Load the resulting dataset into the target triple store

Scripts for all reification schemes are provided in:
```bash
docs/datasets/scripts/

```
## 4. Loading Data into Triple Stores
### GraphDB
```bash
graphdb-import --repository watdivrdfstargraphdb \
               --file article_categories_en-rdf-star.ttls

```
### Stardog
```bash
stardog data add watdivrdfstargraphdb article_categories_en-rdf-star.ttls


```
