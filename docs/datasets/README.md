# Dataset Generation and Reification

This document describes how datasets used in the experiments were generated
and how provenance was encoded using different reification schemes.

---

## 1. Dataset Sources

### WatDiv
- Generator: https://dsg.uwaterloo.ca/watdiv/
- Or direct download 10M: https://dsg.uwaterloo.ca/watdiv/watdiv.10M.tar.bz2   100M: https://dsg.uwaterloo.ca/watdiv/watdiv.100M.tar.bz2 
- Output format: N-Triples (`.nt`)

### Wikidata
- Source: Official Wikidata RDF dumps
- e.g https://doi.org/10.6084/m9.figshare.19599589

### FedShop
- Source: FedShop dataset : [https://zenodo.org/records/12204740](https://zenodo.org/records/12204740/files/fedshop_dataset.zip?download=1)
- Data distributed across multiple SPARQL endpoints

---

## 2. RDF-star Reification

RDF-star datasets are generated by transforming standard N-Triples into
RDF-star annotated triples.

### Example: Article Categories Dataset
The same transformation pipeline is applied to all other datasets by replacing the input .nt file accordingly.
```bash
gzip article_categories_en.nt

zcat article_categories_en.nt.gz | \
awk '{print " ", $0, "{|   <http://example.org/occurrenceOf>     <http://example.org/statement/" \
            NR "> |}  ."}' | \
sed -e 's/\t/ /g' -e 's/. {|/{|/' | \
gzip > article_categories_en-rdf-star.ttls.gz

gunzip article_categories_en-rdf-star.ttls.gz
sed -i 's/\.{|/{|/g' article_categories_en-rdf-star.ttls
